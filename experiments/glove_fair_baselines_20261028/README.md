# GloVe development baselines

Separate CNN/LSTM training, validation and verification code. Obtain authorized frozen development data and original licensed external GloVe assets/provenance before reproduction; embeddings and derived vocabularies are not redistributed. prepare_data.py and prepare_embeddings.py are explicit preparation actions; train_baselines.py requires --smoke or --architecture. No final Test entry point is provided. No baseline training or fresh checkpoint replay was repeated during this release review.
